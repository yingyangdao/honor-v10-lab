## 第一步：开启移动热点（你来，30 秒）

1. 按 **Win + I** 打开设置
2. **网络和 Internet → 移动热点**
3. 「共享我的以下 Internet 连接」选 **以太网 2**
4. 点 **编辑**，改成：
   - 网络名称：**HuaweiCapture**
   - 网络密码：**capture2026**
5. 把「移动热点」开关**打开**
6. 确认页面上显示的网段是 **192.168.137.1**

> 我已经用 API 试过启动，但状态不稳（一会儿 On 一会儿 Off）。**用设置界面开最稳。**

## 第二步：手机连热点

1. 手机 **设置 → WLAN**，连接 **HuaweiCapture**，密码 **capture2026**
2. 如果提示「无法访问互联网」，选 **仍然连接**
3. **务必打开手机浏览器试一下能不能上网** —— 不通的话 eRecovery 也下不了

## 第三步：告诉我热点已开好

我会：
- 确认热点网段和手机在线
- **重启 pktmon 抓包**（会弹 UAC，你点「是」）

## 第四步：进 eRecovery 下载（你来）

1. **手机关机**（拔不拔 USB 都行）
2. 按住 **「音量加」+「电源键」** 约 3 秒 → 进入 **eRecovery** 界面
3. 选 **「下载最新版本并恢复」**（英文：Download latest version and recovery）
4. eRecovery 里选 WiFi：**HuaweiCapture** / **capture2026**
5. 点开始下载
6. **看到进度条开始走就够了** —— 我会在抓包里抓下载地址

## ⚠️ 重要提醒

### 1. eRecovery 会清空手机数据
「下载最新版本并恢复」下载完成后会**直接格式化并重装系统**。

**但这对你反而有好处**：
- 你数据已经备份过了
- 重装的就是 **9.1.0.337**（和当前版本一样）
- **顺手解决了 /data 89% 满导致的卡死问题**
- 而且解锁本来也会清数据，等于是提前做了

### 2. 如果你想避免重装
看到进度条走起来、我确认抓到 URL 之后，你可以**长按电源键强制关机**。
但我不建议 —— 下载中途断电有风险，而且重装对你没坏处。

### 3. 抓包原理
```
手机 ──WiFi──> PC 热点(192.168.137.1) ──ICS NAT──> 以太网 2 ──> 路由器 ──> 华为服务器
                        ↑
                  pktmon 在这里抓
```
华为 OTA 下载历史上走的是 **HTTP**（`http://update.hicloud.com:8180/TDS/...`），
如果是 HTTP，**完整 URL 会明文出现在抓包里**，直接就能用。
