## 一、本轮新突破

### 1. 华为 OTA 接口还活着（重要）

从你手机的 logcat 里抓到了官方 OTA 接口：

```
POST https://query.hicloud.com/sp_ard_common/v2/onestopCheck.action?verType=true&autoInstall=y&latest=true
```

- 实测 GET → 405（说明接口在，只是要 POST）
- 实测 POST 空 JSON → `{"status":"-1"}`（服务器正常响应）
- 手机自己查询返回：`{"status":"1","versionPackageCheckResults":[{"status":"1","versionPackageType":2},...]}`
- 手机日志明确写：**New version not available** → 说明 9.1.0.337 就是最终版，服务器上有这个包

**如果拿到正确的请求体格式，就能用「旧版本号」去查询，服务器会返回 9.1.0.337 的下载地址。** 目前缺的就是 JSON body 格式。

### 2. OTA CDN 已彻底废弃

```
http://update.hicloud.com:8180/TDS/...   → 全部 404
https://update.dbankcdn.com/TDS/...      → 全部 404
```
连 ValdikSS 那份「历史可用链接清单」里的链接现在也 404 了。**URL 爆破路线死亡。**

## 四、拿到 9.1.0.337 之后的路线

1. 用 `appupk.py` 解包 → 取 `dload/XLOADER.img` + `unlockcode`
2. 三键进 **USB DLOAD MODE**（不用拆机）
3. Kirin-Tool SWTP 或 `gobrom.py` 发补丁后的 XLOADER → 踢进 COM 1.0
4. COM 1.0 里解锁 + Dump `recovery_ramdisk`
5. Magisk 修补 → `fastboot flash recovery_ramdisk`
