# 00 · 快速开始

> 5 分钟让这台手机为你干活。

## 0. 前提

手机已经 Root 好（Magisk 20.1），插在电脑上，`adb devices` 能看到。

## 1. 电脑端：设置环境（每次新开终端都要做）

```powershell
cd 'G:\DeepSeek Harness\Root'
. .\scripts\env.ps1
```

它会自动把 `adb` / `build-tools` / `JDK 17` / `apktool` / `frida` 加进 PATH。

## 2. 看一眼手机状态

```powershell
.\scripts\phone.ps1 status
```

输出包含：设备信息、Root 状态、Magisk 版本、模块列表、第三方应用、已冻结应用、系统负载。

## 3. 我要干什么？

### A. 抓某个 App 的 HTTPS 明文

```powershell
# 开代理（手机与电脑不同网段也能用，靠 adb reverse）
.\scripts\proxy.ps1 on 8080

# 另开一个终端跑代理（任选其一）
mitmweb --listen-port 8080            # mitmproxy，推荐
# 或者打开 Charles / Fiddler，监听 8080，勾选 Allow remote clients

# 手机上操作目标 App，代理界面里就能看到明文
```

> 如果 App 报证书错误，说明它有 SSL Pinning，看下一步。

### B. 破 SSL Pinning

```powershell
.\scripts\frida-patch.ps1 -Package com.target.app -Install
```

然后手机上启动 App，电脑上：

```powershell
objection -g com.target.app explore
# 进去后敲：
android sslpinning disable
```

### C. 抓不走代理的流量（非 HTTP / 绕过代理的 App）

```powershell
.\scripts\capture.ps1 start
# ...操作 App...
.\scripts\capture.ps1 stop       # 自动拉回 capture\cap.pcap
```

用 Wireshark 打开 `capture\cap.pcap`。

### D. 装一个 Magisk 模块

```powershell
.\scripts\phone.ps1 install .\mod.zip
adb reboot
```

### E. 连手机的 SSH（当服务器用）

```powershell
.\scripts\phone.ps1 ssh          # 自动建转发 + 登录
# 或者直接双击根目录的「连接手机SSH.bat」
```

用户名 `u0_a123`，密码 `termux2026`（**建议进 Termux 敲 `passwd` 改掉**）。

### F. 以 root 执行命令

```powershell
.\scripts\phone.ps1 su "id"
.\scripts\phone.ps1 su "ls /data/adb/modules"
```
