## 1. Magisk（总控制台）

**入口：手机桌面 → Magisk 图标**

左侧 ☰ 菜单里有 6 项：

| 菜单项 | 干什么 |
|---|---|
| **Magisk**（首页） | 看版本、检查更新、SafetyNet 检查 |
| **超级用户** | 查看/撤销哪些 App 拿到了 root |
| **Magisk Hide** | 勾选要"隐藏 root"的 App（反检测） |
| **模块** | 装/卸/启用/禁用模块 ← **最常用** |
| **下载** | 在线模块商店（已失效，别用） |
| **日志** | 看 Magisk 运行日志 |
| **设置** | 系统级 hosts 开关、核心功能模式、MagiskHide 总开关 |

### 1.1 模块的启用 / 暂停 / 删除

**图形界面**：Magisk → ☰ → 模块
- 每个模块右侧 **✓ / ○ 圆圈** = 点一下切换 **启用 / 禁用**
- **垃圾桶图标** = 删除模块
- 右下 **黄色 + 按钮** = 从存储安装模块 zip

**命令行**（改完要重启生效）：
```bash
# 禁用某个模块
adb shell su -c 'touch /data/adb/modules/busybox-ndk/disable'
# 重新启用
adb shell su -c 'rm /data/adb/modules/busybox-ndk/disable'

# 禁用全部模块（核心功能模式，救砖用）
adb shell su -c 'touch /cache/.disable_magisk'
# 恢复
adb shell su -c 'rm /cache/.disable_magisk'

# 删除模块
adb shell su -c 'rm -rf /data/adb/modules/<模块ID>'
```

**当前 4 个模块的 ID**（文件夹名，不可改）：
`busybox-ndk` · `MagiskHidePropsConf` · `cacerts` · `hosts`

### 1.2 超级用户授权管理
Magisk → ☰ → 超级用户 → 可以：
- 看到所有申请过 root 的 App 和它们的状态
- 点某个 App → **撤销 / 改为"允许"或"拒绝"**

当前：`com.android.shell`（adb）是**永久允许**；AdAway 已授予；Termux 需要用时才申请。

### 1.3 MagiskHide（反检测）
Magisk → ☰ → Magisk Hide
- 顶部总开关 = 启用/停用整个 MagiskHide
- 列表里勾选 App = 对这些 App 隐藏 root

当前状态：**已启用**。

### 1.4 系统级 hosts 开关

## 2. AdAway（全机去广告）

**入口：手机桌面 → AdAway 图标**

主界面：

| 元素 | 作用 |
|---|---|
| 顶部三个数字 | 阻止 / 允许 / 重定向 的条数 |
| 中间卡片「3 个已更新来源」+ **🔄 图标** | 点它 = 检查并更新广告源 |
| 中间卡片 + **⬇ 图标** | 下载/应用 hosts |
| 底部**大红圆按钮** | **暂停图标(⏸)= 正在拦截，点一下暂停**；**播放图标(▶)= 已暂停，点一下恢复** |
| 左下 ☰ 菜单 | 设置、来源管理、DNS 请求记录 |

**查看当前生效的拦截条数**：
```bash
adb shell su -c 'wc -l /system/etc/hosts'
adb shell su -c 'head -8 /system/etc/hosts'    # 能看到生成时间和来源
```

**暂停 AdAway 的三种办法**：
1. AdAway 界面点底部大红按钮
2. `adb shell su -c 'rm -rf /data/adb/modules/hosts' && adb reboot`（连模块一起删）
3. 把 `/data/adb/modules/hosts` 改名加 `disable`（重启后失效但保留文件）

当前：**已启用，71,505 条规则**，3 个来源（AdAway 官方 / Pete Lowe / StevenBlack Unified）。

## 3. Termux + SSH 服务 ⭐

**入口：手机桌面 → Termux 图标**

### 3.1 连接信息

| 项 | 值 |
|---|---|
| 用户名 | `u0_a123` |
| 密码 | `termux2026` ← **建议改掉** |
| 端口 | `8022` |
| 手机局域网 IP | `192.168.5.16`（WiFi：风生水起-5G） |
| USB 转发地址 | `127.0.0.1:8022`（走 adb） |

> ⚠️ 你电脑的网段是 `192.168.9.x`（以太网），手机是 `192.168.5.x`，**不在同一个局域网**，所以电脑现在直连不到手机 IP。
> 两种解法：① 让手机连到电脑同一个网（192.168.9.x）；② 直接用 USB 转发（下面这个 .bat 就是干这个的）。

### 3.2 电脑上怎么连（推荐）

双击 **[连接手机SSH.bat](G:\DeepSeek%20Harness\Root\连接手机SSH.bat)**
它会自动：建立 adb 端口转发 → 调起 ssh → 提示你输入密码 `termux2026`

或者手动：
```powershell
# 1. 建立 USB 转发（插着数据线才有效）
& "C:\Users\wangyang\AppData\Local\Android\Sdk\platform-tools\adb.exe" forward tcp:8022 tcp:8022

# 2. 连接（已经写进 ~/.ssh/config，直接 ssh termux 即可）
ssh termux
# 密码：termux2026
```

> ⚠️ **Windows 自带的 ssh.exe（9.5 版）有个 bug**：遇到新版 OpenSSH 服务端会走
> `publickey-hostbound` 路径然后静默失败（报 `Permission denied`）。
> 我已经在 `~/.ssh/config` 里给 `termux` 这个主机加了 `PubkeyAuthentication no` 绕开它，**用密码登录就正常**。
> 如果想用密钥登录，用 **plink**：`G:\DeepSeek Harness\Root\tools\plink.exe`（已下好，实测可用）。

### 3.3 在手机上控制 SSH 服务

在 Termux 里敲：

| 命令 | 作用 |
|---|---|
| `sshd` | **启动** SSH 服务 |
| `pkill sshd` | **停止** SSH 服务 |
| `pgrep -x sshd` | 看有没有在跑（有输出=在跑） |
| `netstat -tln \| grep 8022` | 看端口是否在监听 |
| `passwd` | **改密码**（输两遍新密码） |
| `whoami` | 看用户名 |
| `ifconfig wlan0` | 看手机 IP |
| `exit` | 退出当前会话 |

在电脑上用 adb 控制：
```bash
# 查看状态
adb shell netstat -tln | findstr 8022
# 强制停掉
adb shell su -c 'pkill -f sshd'
```

### 3.4 开机自动启动（已配置，但需要你点 3 下）

我装了 **Termux:Boot**，它会开机跑 `~/.termux/boot/10-sshd.sh`。

**但华为 EMUI 默认禁止第三方 App 自启动**，所以你需要手动放行一次：

> **设置 → 应用 → 应用启动管理 → 找到 Termux 和 Termux:Boot → 关掉"自动管理" → 三个开关（自启动 / 关联启动 / 后台活动）全部打开**

**兜底方案（已生效）**：就算 EMUI 不放行，你只要**打开一次 Termux**，`~/.bashrc` 里的钩子就会自动把 sshd 拉起来，不用手敲命令。

相关文件：
- 开机脚本：`~/.termux/boot/10-sshd.sh`
- 兜底钩子：`~/.bashrc` 末尾
- 开机日志：`~/boot.log`（能看到 `sshd started at ...` 就说明 Termux:Boot 生效了）
- 临时开关：`~/.termux/termux.properties` 里的 `allow-external-apps=true`

### 3.5 Termux 常用包管理

pkg install <包名>     # 装软件，例：pkg install python nodejs git
pkg list-installed    # 已装列表
pkg uninstall <包名>   # 卸载
```

```

## 9. 常见故障速查

| 症状 | 处理 |
|---|---|
| sshd 连不上 | 手机打开 Termux 敲 `sshd`；电脑重跑一次 adb forward |
| `ssh termux` 报 Permission denied | 确认 `~/.ssh/config` 里有 `PubkeyAuthentication no`；或改用 `连接手机SSH.bat` |
| Magisk 里模块全没了 | 检查 `/data/adb/modules` 是否还在；用 `su -c 'magisk --restorecon'` |
| 开机卡住 | 进 recovery 建 `/cache/.disable_magisk`，或用 adb `touch /data/adb/modules/<ID>/disable` |
| `pm` 报 Failed transaction | 别用 `su -c` 跑 pm，直接用 `adb shell pm ...` |
| `dd` 报 illegal number | toybox 的 dd 不认 `bs=1M`，写 `bs=1048576` |
| 系统很卡 | 见下一节 |
